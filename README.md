## 板卡主要功能块

| 功能块 | 说明 |
| --- | --- |
| 主控 | STM32 系列 MCU（LQFP64），外部 8MHz 晶振 + SWD 调试口 |
| 电源 | 12V 输入 → MP2315 降压；TLV70233 提供 3.3V，输入 TVS 保护 |
| 电机驱动 | TMC2208 步进驱动（针阀开度调节） |
| 通信 | RS485（SP3485 + SM712 防护）、CAN 接口 |
| 采样 | 流量计 ADC 输入通道、TMAG5170 磁传感 |
| 接口 | XH2.54 下载/扩展/5V 输入、LED 指示 |
